# Authentication

All API requests require authentication using an API key. This guide covers how to create, manage, and use API keys securely.

## API Keys

API keys are the primary method of authenticating with the Verifact API. Each key is:

- Scoped to your organization
- Trackable for usage and billing
- Revocable at any time

### Creating an API Key

1. Navigate to your [Dashboard](/dashboard/keys)
2. Click **Create New Key**
3. Give your key a descriptive name (e.g., "Production Server", "Development")
4. Copy the key immediately - it won't be shown again

<Callout type="danger" title="Important">
API keys are only displayed once upon creation. Store them securely in your environment variables or secrets manager.
</Callout>

## Using API Keys

Include your API key in the `Authorization` header with the `Bearer` scheme:

```bash
Authorization: Bearer vfy_abc123...
```

## Security Best Practices

### Do

- Store API keys in environment variables
- Use different keys for development and production
- Rotate keys periodically
- Delete keys that are no longer needed

### Don't

- Commit API keys to version control
- Expose keys in client-side code
- Share keys across teams without tracking
- Use production keys for testing

## Managing Keys

### Viewing Usage

Each API key tracks its usage automatically. View statistics in your [Dashboard](/dashboard/keys):

- Total requests made
- Last used timestamp
- Active/inactive status

### Revoking Keys

To revoke a compromised or unused key:

1. Go to [Dashboard → API Keys](/dashboard/keys)
2. Find the key you want to revoke
3. Click the **Delete** button
4. Confirm the deletion

<Callout type="warning">
Revoking a key is immediate and permanent. Any applications using that key will receive `401 Unauthorized` errors.
</Callout>
