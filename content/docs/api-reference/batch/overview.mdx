# Batch Processing

The Batch API allows you to verify multiple pieces of content in a single request. This is ideal for bulk content moderation, historical data verification, and automated pipelines.

<Callout type="info">
Batch processing is available on Pro and Enterprise plans only.
</Callout>

## How It Works

1. **Upload** (optional) - Upload a CSV or JSON file via `/v1/batch/upload`
2. **Create** - Create a batch job via `/v1/batch` with items or a file reference
3. **Process** - Items are verified asynchronously in parallel
4. **Retrieve** - Poll for status or fetch results when complete

## Batch Lifecycle

| Status | Description |
|--------|-------------|
| `pending` | Batch created, awaiting processing |
| `validating` | Parsing and validating input items |
| `processing` | Items actively being verified |
| `completed` | All items processed successfully |
| `failed` | Batch-level failure (validation errors) |
| `cancelled` | User cancelled the batch |

## Limits

| Limit | Value |
|-------|-------|
| Maximum items per batch | 100 |
| Maximum file upload size | 10 MB |
| Maximum content length per item | 50,000 characters |
| File reference expiry | 1 hour |
| Results retention | 30 days |

## Available Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | [`/v1/batch`](/docs/api-reference/batch/create-batch) | Create a batch job |
| `GET` | [`/v1/batch`](/docs/api-reference/batch/list-batches) | List batch jobs |
| `GET` | [`/v1/batch/:id`](/docs/api-reference/batch/get-batch) | Get batch status |
| `GET` | [`/v1/batch/:id/results`](/docs/api-reference/batch/get-results) | Get batch results |
| `POST` | [`/v1/batch/:id/cancel`](/docs/api-reference/batch/cancel-batch) | Cancel a batch |
| `POST` | [`/v1/batch/upload`](/docs/api-reference/batch/upload-file) | Upload batch file |

## Real-time Updates

Subscribe to batch progress via Supabase Realtime:

```javascript
const channel = supabase.channel(`batch:${batchId}`);

channel.on('broadcast', { event: 'progress' }, ({ payload }) => {
  console.log(`Progress: ${payload.processedItems}/${payload.totalItems}`);
});

channel.subscribe();
```
