# Get Batch

Retrieve the status and details of a specific batch job.

<EndpointHeader
  method="GET"
  path="/v1/batch/:id"
  description="Get detailed information about a batch job including progress."
/>

## Path Parameters

<ParameterTable
  title="Parameters"
  parameters={[
    {
      name: 'id',
      type: 'string',
      required: true,
      description: 'The batch ID (prefixed with batch_)',
    },
  ]}
/>

## Polling for Completion

```javascript
async function waitForBatch(client, batchId, intervalMs = 2000) {
  while (true) {
    const batch = await client.getBatch(batchId);

    if (batch.status === 'completed' || batch.status === 'failed' || batch.status === 'cancelled') {
      return batch;
    }

    console.log(`Progress: ${batch.processedItems}/${batch.totalItems}`);
    await new Promise(resolve => setTimeout(resolve, intervalMs));
  }
}
```

<Callout type="tip">
Use the SDK's `createBatchAndWait()` method for automatic polling with exponential backoff.
</Callout>
