# Get Batch Results

Retrieve the verification results for items in a batch.

<EndpointHeader
  method="GET"
  path="/v1/batch/:id/results"
  description="Get paginated verification results for a batch job."
/>

## Path Parameters

<ParameterTable
  title="Path Parameters"
  parameters={[
    {
      name: 'id',
      type: 'string',
      required: true,
      description: 'The batch ID (prefixed with batch_)',
    },
  ]}
/>

## Query Parameters

<ParameterTable
  title="Query Parameters"
  parameters={[
    {
      name: 'limit',
      type: 'integer',
      required: false,
      description: 'Number of results to return. Default: 50, Maximum: 100.',
      default: '50',
    },
    {
      name: 'offset',
      type: 'integer',
      required: false,
      description: 'Number of results to skip for pagination.',
      default: '0',
    },
    {
      name: 'status',
      type: 'string',
      required: false,
      description: 'Filter by item status: pending, queued, processing, completed, failed, skipped.',
    },
  ]}
/>

### Item Statuses

| Status | Description |
|--------|-------------|
| `pending` | Item created, not yet queued |
| `queued` | Item sent to processing queue |
| `processing` | Item currently being verified |
| `completed` | Verification completed successfully |
| `failed` | Verification failed after retries |
| `skipped` | Item skipped (batch was cancelled) |

### Error Responses

**404 Not Found**
```json
{
  "error": {
    "code": "not_found",
    "message": "Batch not found"
  }
}
```

## Fetching All Results

```javascript
async function fetchAllResults(client, batchId) {
  const allItems = [];
  let offset = 0;
  const limit = 100;

  while (true) {
    const results = await client.getBatchResults(batchId, { limit, offset });
    allItems.push(...results.items);

    if (!results.pagination.hasMore) break;
    offset += limit;
  }

  return allItems;
}
```

## Filtering Failed Items

```bash
# Get only failed items
curl -X GET "https://api.verifact.ai/v1/batch/batch_abc123/results?status=failed" \
  -H "Authorization: Bearer vfy_your_api_key"
```
