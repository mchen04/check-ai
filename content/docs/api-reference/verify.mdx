# Verify Content

Submit content for AI-powered verification analysis.

<EndpointHeader
  method="POST"
  path="/v1/verify"
  description="Analyze content and return a verification verdict with confidence score."
/>

## Request Body

<ParameterTable
  title="Parameters"
  parameters={[
    {
      name: 'content',
      type: 'string',
      required: true,
      description: 'The text content to verify. Maximum 10,000 characters.',
    },
    {
      name: 'mode',
      type: 'string',
      required: false,
      description: 'Verification mode: "fast" (single paradigm) or "standard" (multi-paradigm)',
      default: '"standard"',
    },
    {
      name: 'paradigms',
      type: 'string[]',
      required: false,
      description: 'Specific paradigms to use. If omitted, uses optimal set based on mode.',
    },
    {
      name: 'webhookUrl',
      type: 'string',
      required: false,
      description: 'URL to receive webhook notification when verification completes.',
    },
    {
      name: 'metadata',
      type: 'object',
      required: false,
      description: 'Custom metadata to attach to the verification (max 1KB).',
    },
  ]}
/>

### Available Paradigms

| Paradigm | Description |
|----------|-------------|
| `llm_analysis` | LLM-based reasoning and analysis |
| `search_verification` | Cross-reference with authoritative sources |
| `logical_consistency` | Check for internal contradictions |
| `source_reputation` | Evaluate cited source credibility |
| `temporal_analysis` | Verify information currency |
| `synthetic_detection` | Detect AI-generated content |
| `contextual_analysis` | Understand framing and nuance |

## Verification Modes

### Fast Mode

Uses a single paradigm (LLM analysis) for quick results:
- Response time: ~500ms
- Cost: 1 credit
- Best for: High-volume, low-stakes verification

### Standard Mode (Default)

Uses multiple paradigms for comprehensive analysis:
- Response time: 2-5 seconds
- Cost: 5 credits
- Best for: Important content requiring high accuracy

<Callout type="info">
For real-time applications, consider using webhooks with standard mode to get accurate results asynchronously.
</Callout>
